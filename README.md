# 🎨 SASS Composition Project

A structured front-end layout created as part of learning **SASS composition techniques**, including partials, modules, nesting, and reusable styles.

🔗 **Live Demo:** [sham-sbehat-composition-sass-project.netlify.app](https://sham-sbehat-composition-sass-project.netlify.app/)

## 📝 Description

This project focuses on:

- Practicing advanced SASS (SCSS) structuring.
- Using partial files for organization (e.g., `_variables.scss`, `_layout.scss`, `_buttons.scss`).
- Implementing nesting, mixins, and reusable class utilities.
- Creating a clean UI layout as a test environment for modular SCSS design.

🎯 **Main Goal:**  
To improve understanding of **SCSS architecture** and how to write scalable, maintainable CSS using SASS composition patterns.

## 🛠️ Built With

- **HTML5**
- **SASS (SCSS)**
